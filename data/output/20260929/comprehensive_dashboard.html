📊 Drift Detection System

▼
🎯 Drift Detection Concept: Track changes in Wikidata mappings over time to identify:
  • New violations: Recently added duplicate mappings
  • Fixed violations: Previously reported issues that are now resolved
  • Drift: Mappings that have changed or been removed
  • Trends: Patterns in how mappings evolve

Implementation Plan

✅ Phase 1: Baseline
Run complete scan today as baseline
🔄 Phase 2: Periodic Scans
Schedule weekly/monthly re-scans
📊 Phase 3: Comparison
Compare scans to detect changes
📈 Phase 4: Dashboard
Visualize drift in this dashboard

What We Can Detect

Change TypeDescriptionSeverity
New Violation Wikidata added a duplicate P8814/P5063 statement ⚠️ High
Fixed Violation Previously reported violation is now resolved ✅ Good
Mappings Drift QID changed its P8814/P5063 value ⚠️ Medium
New Mapping QID gained a new P8814/P5063 statement ℹ️ Low
Removed Mapping QID lost a P8814/P5063 statement ℹ️ Low
